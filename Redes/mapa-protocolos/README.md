# Mapa de protocolos de comunicación de red

Póster interactivo de las siete capas OSI y de las familias de protocolos que se apoyan en ellas: TCP/IP, UNIX, Novell, Microsoft, SAN, IBM, ISO, VoIP, VPN y seguridad, y Apple. Se puede buscar un protocolo, ampliar el póster y abrir el grafo Mermaid de cada familia.

[Abrir el mapa interactivo](https://p3m-actf.github.io/Biblioteca/Redes/mapa-protocolos/) · [Consultar el HTML](index.html). El diagrama se dibuja con Mermaid cargado desde jsDelivr, así que hace falta conexión para verlo. Si no hay red, el código del grafo se puede copiar y pegar en [mermaid.live](https://mermaid.live).

El botón **Imprimir / PDF** permite guardar el póster como PDF desde el navegador. Los grafos están también sueltos en [mermaid/](mermaid/), uno por familia más la vista general.

La chuleta de capas, puertos y estados TCP es [modelo y puertos](../chuletas/modelo-puertos.md). El hilo narrativo, con un diagrama por capa, está en la wiki: [Mapa de protocolos](https://github.com/P3M-ACTF/Biblioteca/wiki/Mapa-de-protocolos).
