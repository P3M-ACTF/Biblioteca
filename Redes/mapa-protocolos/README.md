# Mapa de protocolos de red

Lista de consulta de las siete capas OSI y de las familias de protocolos que se apoyan en ellas: TCP/IP, UNIX, Novell, Microsoft, SAN, IBM, ISO, VoIP, VPN y seguridad, y Apple. Cada protocolo lleva una línea de para qué sirve. Desde la página se abre el grafo Mermaid de la familia.

[Abrir el mapa](index.html). GitHub muestra el HTML como código; para usarlo, descarga el fichero o clona el repositorio y ábrelo en el navegador. El diagrama se dibuja con Mermaid cargado desde jsDelivr, así que hace falta red la primera vez. Si no hay red, el código del grafo se puede copiar y pegar en [mermaid.live](https://mermaid.live).

Los grafos están también sueltos en [mermaid/](mermaid/), uno por familia más la vista general.

La chuleta de capas, puertos y estados TCP es [modelo y puertos](../chuletas/modelo-puertos.md). El hilo narrativo, con un diagrama por capa, está en la wiki: [Mapa de protocolos](https://github.com/P3M-ACTF/Biblioteca/wiki/Mapa-de-protocolos).

Esto no reproduce ningún póster comercial. Recoge qué protocolo vive en qué capa, que es información de referencia, y la presenta como lista.
