# SSH · Inventario de configuración

[Índice de SSH](README.md) · [Guion general](../ssh.md)

Base: **OpenSSH Portable 10.6p1**, commit `a8c72b842423f0774f542d3c2197247c3dd28d74`. Hay una entrada por cada directiva principal documentada: **104 de cliente y 107 de servidor**. Los nombres heredados que conserva el parser se recogen aparte.

## Trabajo obligatorio por directiva

Las gramáticas de las tablas delimitan los argumentos y variantes que debemos explicar; no sustituyen la sintaxis completa del manual. En cada ficha:

- [ ] Enumerar valores admitidos y alias, tipo, rango, unidades, default y requisitos de compilación.
- [ ] Probar omisión, valor válido/inválido, repetición, precedencia, quoting y expansión de rutas/tokens.
- [ ] Explicar si toma la primera asignación, acumula valores o tiene otra regla; no generalizar entre directivas.
- [ ] En cliente, comparar CLI, configuración personal/global, Host/Match, canonicalización e Include con `ssh -G`.
- [ ] En servidor, comparar global/Match e Include con `sshd -T -C ...`; distinguirlo de `-G` y `-t`.
- [ ] Registrar privilegios, lectura/escritura, persistencia, recarga, impacto de seguridad y recuperación.

Los nombres de directiva son insensibles a mayúsculas, pero se conserva la grafía del manual. No convertir automáticamente sus valores a minúsculas. Las listas de algoritmos se completan con el catálogo de la compilación objetivo, no con una lista universal supuesta.

## Subvalores y gramáticas compartidas

El [inventario de formatos y casos](formatos-y-casos.md) desglosa criterios Match, tipos de canal, penalizaciones por origen, tokens, tiempos, formatos de clave y restricciones por clave. Las siguientes gramáticas necesitan fichas propias, además de las directivas que las usan:

- [ ] **Patrones:** `*`, `?`, negación `!`, listas con comas y reglas de coincidencia negativa.
- [ ] **Listas de algoritmos:** lista explícita, suma `+`, retirada `-`, prioridad `^`, comodines, orden y algoritmo no compilado.
- [ ] **Tiempos:** número y unidades `s/S`, `m/M`, `h/H`, `d/D`, `w/W`; composición, cero y reglas de cada consumidor.
- [ ] **Direcciones:** IPv4, IPv6 con corchetes, CIDR, host:puerto, wildcard, localhost, puertos cero/dinámicos cuando proceda y sockets Unix.
- [ ] **IPQoS:** `af11/12/13`, `af21/22/23`, `af31/32/33`, `af41/42/43`, `cs0…cs7`, `ef`, `le`, numérico y `none`; uno o dos argumentos.
- [ ] **Autenticación:** `gssapi-with-mic`, `hostbased`, `keyboard-interactive[:dispositivo]`, `none`, `password`, `publickey`; `any`, comas frente a espacios y disponibilidad real.
- [ ] **Variables y tokens:** diferencias entre `$VAR`, `${VAR}`, `%`, tilde, comillas y shell; solo se expanden donde el manual lo permite.

El contexto servidor de las tablas se obtiene de `SSHCFG_ALL/GLOBAL` en `servconf.h` y de las entradas Match/Include del parser. No sustituye las pruebas de una compilación concreta: PAM, Kerberos/GSSAPI, routing domains y otros elementos dependen del sistema y de las opciones de build. La explicación completa de defaults y pruebas permanece pendiente.
