## Formatos adicionales y valores sin tabla propia

- [ ] **authorized_keys:** campos opciones, tipo, base64 y comentario; blanco/comentario, comillas, clave malformada y entradas duplicadas.
- [ ] **known_hosts:** marcador opcional, lista de hosts, tipo, base64 y comentario; `@cert-authority`, `@revoked`, host:puerto, wildcard/negación y host hasheado `|1|salt|hash`.
- [ ] **authorized_principals:** opciones y lista de principals; fichero frente a comando, usuario local y certificado.
- [ ] **allowed_signers:** principals, opciones, tipo y clave; namespace, tiempo de verificación y coincidencia con principal de certificado.
- [ ] **Clave privada:** formato OpenSSH, cifrado, KDF, passphrase y permisos; distinguir conversión de formato y cambio de algoritmo.
- [ ] **Certificado SSH:** algoritmo/tipo, serial, key ID, principals, CA, validez, critical options y extensiones; no confundir con X.509.
- [ ] **KRL:** clave, serial/rango, ID y fingerprints; generar, actualizar, listar y consultar; retorno cuando una clave está revocada.
- [ ] **moduli:** tipos `0/2/4`, bits de tests `0x00/0x01/0x02/0x04`, timestamp, tamaño y representación hexadecimal.
- [ ] **Validez -V:** instantes absolutos, sufijo Z, intervalos relativos, hexadecimal Unix, rangos abiertos/forever e incrementos de serial con +.
- [ ] **Agente -O:** `allow-remote-pkcs11`, `no-restrict-websafe`, `websafe-allow=<patrones>`; política predeterminada y efecto específico de cada excepción.
- [ ] **Agente -A:** `user:<ruta>` y `shared:<ruta-absoluta>`; tokens admitidos, permisos, limpieza y diferencia con -a/-T.
- [ ] **ChannelTimeout:** incluir `global` además de los tipos de las tablas; cero y coincidencias por wildcard.
- [ ] **PerSourcePenalties:** `yes/no`, `overflow/overflow6` con `deny-all/permissive`; acumulación, exenciones y límites IPv4/IPv6.
- [ ] **Match cliente:** `sessiontype` con `shell/exec/subsystem/none`, además de los criterios enumerados en [configuración](configuracion.md).
- [ ] **Solicitudes SFTP:** las unidades siguientes son nombres del protocolo, no órdenes del intérprete interactivo.

## Matriz de casos

Cada caso exige precondición, acción, stdout/stderr o log, código de retorno y criterio de éxito/fallo; conservar la evidencia y el entorno. Las casillas permanecen abiertas hasta ejecutar el caso. Enlazar sus variantes a las unidades de CLI/configuración/formatos correspondientes.

- [ ] <a id="ssh-i-case-001"></a>**SSH-I-CASE-001 · Conexión mínima.** Usuario/host/puerto correctos; DNS erróneo, timeout, conexión rechazada y familia incorrecta.
- [ ] <a id="ssh-i-case-002"></a>**SSH-I-CASE-002 · Quoting.** Espacios, comillas, dos puntos, wildcard, Unicode y doble interpretación local/remota.
- [ ] <a id="ssh-i-case-003"></a>**SSH-I-CASE-003 · Host nuevo.** Huella obtenida por canal independiente; aceptación interactiva y ejecución BatchMode.
- [ ] <a id="ssh-i-case-004"></a>**SSH-I-CASE-004 · Host cambiado.** Cambio legítimo frente a suplantación; aceptación de clave nueva no equivale a aceptar clave cambiada.
- [ ] <a id="ssh-i-case-005"></a>**SSH-I-CASE-005 · Identidad.** Clave explícita, predeterminada, certificado, agente presente/ausente, demasiadas identidades y orden de -Z.
- [ ] <a id="ssh-i-case-006"></a>**SSH-I-CASE-006 · Passphrase.** Clave sin cifrar/cifrada, interactivo frente a lote y secreto sin aparecer en argv/log.
- [ ] <a id="ssh-i-case-007"></a>**SSH-I-CASE-007 · Permisos.** Owner/modo/ACL de home/.ssh/authorized_keys y clave privada; Unix y Windows por separado.
- [ ] <a id="ssh-i-case-008"></a>**SSH-I-CASE-008 · Configuración cliente.** Precedencia CLI/personal/global; primera asignación, acumulación, Include, Host y negación.
- [ ] <a id="ssh-i-case-009"></a>**SSH-I-CASE-009 · Match cliente.** Cada criterio, argumento omitido, negación, canonical/final, tagged/command/sessiontype y exec con éxito/fallo.
- [ ] <a id="ssh-i-case-010"></a>**SSH-I-CASE-010 · Configuración servidor.** -t frente a -G/-T, -C por usuario/host/IP/puerto, global/Match y directiva prohibida en ese contexto.
- [ ] <a id="ssh-i-case-011"></a>**SSH-I-CASE-011 · Métodos de autenticación.** Cada método compilado, listas alternativas/compuestas, dos claves diferentes y método deshabilitado.
- [ ] <a id="ssh-i-case-012"></a>**SSH-I-CASE-012 · Sesión/TTY.** Shell, comando, subsistema, sin comando, stdin cerrado, TTY/no TTY y código del proceso remoto.
- [ ] <a id="ssh-i-case-013"></a>**SSH-I-CASE-013 · Escapes.** Cada escape; inicio de línea, EscapeChar distinto/none y consola de forwarding habilitada/deshabilitada.
- [ ] <a id="ssh-i-case-014"></a>**SSH-I-CASE-014 · Multiplexación.** Cada -O, maestro nuevo/existente/ausente, ControlPath, ControlPersist y cierre de una sesión frente a maestro.
- [ ] <a id="ssh-i-case-015"></a>**SSH-I-CASE-015 · Forwarding local.** Cada forma TCP/Unix; bind local/wildcard, puerto ocupado, destino no alcanzable y restricciones.
- [ ] <a id="ssh-i-case-016"></a>**SSH-I-CASE-016 · Forwarding remoto.** Cada forma, SOCKS remoto, puerto cero si procede, GatewayPorts y PermitListen/PermitOpen.
- [ ] <a id="ssh-i-case-017"></a>**SSH-I-CASE-017 · SOCKS local.** DNS local/remoto según aplicación cliente, destinos permitidos y origen del tráfico.
- [ ] <a id="ssh-i-case-018"></a>**SSH-I-CASE-018 · Bastión.** Uno/varios saltos, identidades distintas y fallo de un salto sin reenviar el agente innecesariamente.
- [ ] <a id="ssh-i-case-019"></a>**SSH-I-CASE-019 · X11/TUN.** Cada modo, soporte del extremo, permisos y restricciones; no extrapolar a sistemas que no lo admitan.
- [ ] <a id="ssh-i-case-020"></a>**SSH-I-CASE-020 · Agente.** Carga/listado/retirada, expiración, bloqueo/desbloqueo, confirmación, restricciones de destino y socket inaccesible.
- [ ] <a id="ssh-i-case-021"></a>**SSH-I-CASE-021 · Proveedores.** PKCS#11/FIDO con/sin soporte, biblioteca permitida/denegada, PIN y origen local/forwarded.
- [ ] <a id="ssh-i-case-022"></a>**SSH-I-CASE-022 · FIDO.** Presencia/verificación, residente/no residente, cada -O, -p para requisitos y recuperación de claves.
- [ ] <a id="ssh-i-case-023"></a>**SSH-I-CASE-023 · Certificado usuario.** CA, principals, key ID, serial, intervalo y cada critical option/extensión.
- [ ] <a id="ssh-i-case-024"></a>**SSH-I-CASE-024 · Certificado host.** Hostnames, @cert-authority, CA no confiable y certificado válido/expirado/revocado.
- [ ] <a id="ssh-i-case-025"></a>**SSH-I-CASE-025 · Firma de datos.** Cada -Y, namespace/identidad correctos e incorrectos, allowed_signers, timestamp y archivo alterado.
- [ ] <a id="ssh-i-case-026"></a>**SSH-I-CASE-026 · Revocación.** Cada directiva KRL, serial/rango/ID/clave/hash, actualización, clave desconocida y retorno no cero.
- [ ] <a id="ssh-i-case-027"></a>**SSH-I-CASE-027 · SSHFP.** Cada hashalg, DNS seguro/no seguro, registro ausente y fingerprint por canal independiente.
- [ ] <a id="ssh-i-case-028"></a>**SSH-I-CASE-028 · DH-GEX.** Generación/screening, cada -O, reanudación por checkpoint, parámetros inválidos y build sin OpenSSL.
- [ ] <a id="ssh-i-case-029"></a>**SSH-I-CASE-029 · Copia SCP/SFTP.** Modo actual frente a -O legacy, cada flag, archivo/directorio/symlink y remoto-remoto con aviso de -R.
- [ ] <a id="ssh-i-case-030"></a>**SSH-I-CASE-030 · SFTP interactivo.** Cada orden, alias y flag; diferencia local/remoto y extensión no soportada.
- [ ] <a id="ssh-i-case-031"></a>**SSH-I-CASE-031 · SFTP batch.** Error que aborta, prefijos -/@, orden fallida permitida y resultado/log verificables.
- [ ] <a id="ssh-i-case-032"></a>**SSH-I-CASE-032 · Reanudación.** Parcial coincidente/no coincidente, transferencia interrumpida, metadatos y flush.
- [ ] <a id="ssh-i-case-033"></a>**SSH-I-CASE-033 · SFTP restringido.** internal-sftp/chroot, listas permitidas/denegadas, solo lectura y cada solicitud relevante.
- [ ] <a id="ssh-i-case-034"></a>**SSH-I-CASE-034 · Logs y límites.** Verbosity, syslog/archivo/stderr, timeouts, penalizaciones, MaxStartups/MaxSessions y carga controlada.
- [ ] <a id="ssh-i-case-035"></a>**SSH-I-CASE-035 · Compatibilidad.** Cada opción/nombre heredado: ignorado, warning, rechazado o alias; cliente y servidor de distinta versión.
- [ ] <a id="ssh-i-case-036"></a>**SSH-I-CASE-036 · Recuperación.** Validación previa, segunda sesión, recarga, fallo intencional y reversión conservando acceso.
- [ ] <a id="ssh-i-case-037"></a>**SSH-I-CASE-037 · Empaquetado.** Misma operación en la versión objetivo Linux/Windows; rutas, servicio, ACL, build flags y helpers.
